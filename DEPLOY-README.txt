ShubhSutra storefront

Local development
1. Install Node.js.
2. Run npm install.
3. Run npm run dev and open the local address Vite prints.

Netlify deployment
1. Connect the repository to Netlify.
2. Netlify uses netlify.toml to run npm run build and publish dist/.
3. WhatsApp enquiries use the configured business number 91 73404 50358.
   To change it, set VITE_WHATSAPP_NUMBER in the Netlify environment variables.
   Enter digits only, including the country code.

Orders are enquiry-led and continue in WhatsApp. The site does not collect payment.
Review product contents, prices, stock, delivery terms and policies before publishing.
